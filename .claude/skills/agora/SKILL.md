# agora — 철학 토론장

질문 하나를 철학자들의 토론에 부친다. **각 철학자는 매번 새로 띄운 독립된 서브에이전트**가 맡는다.
서로의 머릿속을 공유하지 않고, 오직 기록된 발언만 보고 응답한다. 여는 발언에서는 서로의 말을 아예 보지 못한다.

너(메인 Claude)는 **서기**다. 토론자를 띄우고 순서를 진행할 뿐, 절대 직접 발언하거나 편을 들거나 결과를 고치지 않는다.

이 스킬의 스크립트 경로는 `${CLAUDE_SKILL_DIR}/agora.py`다. 변수가 펼쳐지지 않았다면 위에 출력된
"Base directory for this skill" 경로 아래의 `agora.py`를 쓴다. 아래에서 `AGORA`는 `python3 <그 경로>`를 뜻한다.

## 1단계: 질문 받기

인자에서 질문과 플래그를 분리한다. 질문이 없으면 사용자에게 한 줄로 묻고 기다린다.

| 플래그 | 의미 |
| --- | --- |
| `--panel a,b,c` | 토론자 직접 지정 (`AGORA list`로 목록 확인) |
| `--size N` | 무작위 토론자 수, 기본 5. 서로 다른 전통에서 먼저 뽑는다 |
| `--rounds R` | 반박 라운드 수 0~4, 기본 2 |
| `--quick` | `--size 3 --rounds 1`의 줄임 |
| `--models sonnet,opus,haiku` | 토론자마다 모델을 돌아가며 배정 |
| `--lang en` | 영어로 진행 |
| `--seed S` | 무작위 패널 고정 |

질문이 너무 모호하면(예: "삶이란?") 토론이 가능하도록 한 문장 명제로 다듬자고 제안할 수 있다. 다만 사용자가 원래 질문을 원하면 그대로 쓴다.

## 2단계: 토론 열기

```bash
AGORA init --question "<질문>" [플래그]
```

출력된 토론자 명단과 서브에이전트 호출 수(`subagent_calls`)를 사용자에게 한 줄로 알린다.
호출 하나하나가 사용자의 사용량에 포함되니, 수가 크면 `--quick`을 쓸 수 있다고 함께 알린다.
파일 승인 창이 계속 뜨지 않도록 accept-edits 모드(Shift+Tab)를 켜 두라고 안내한다.

## 3단계: 진행 (항상 `AGORA next`로 구동)

```bash
AGORA next
```

출력 JSON의 `status`에 따라:

- **`dispatch`** 또는 **`retry`**: `tasks`의 모든 항목에 대해 서브에이전트를 **한 메시지 안에서 병렬로** 띄운다.
  - 도구: Agent(또는 Task), `subagent_type`: `general-purpose`
  - `prompt`: 각 task의 `prompt` 필드를 **그대로** 쓴다. 브리프 내용을 요약하거나 덧붙이지 않는다.
  - `model`: task에 값이 있으면 그대로 넘기고, `null`이면 생략한다.
  - `description`: 예) "칸트 — 여는 발언"
  - 전부 끝나면 다시 `AGORA next`.
- **`retry`가 같은 토론자에 대해 두 번째로 나오면** `AGORA skip --id <id>`로 그 토론자를 이번 차례 침묵 처리하고 진행한다.
- **`done`**: 4단계로.

단계 사이에 사용자에게 진행 상황을 짧게 한 줄씩만 알린다(예: "여는 발언 끝, 반박 1라운드 시작").
**하지 말 것:** 출력 파일을 직접 쓰거나 고치기, 토론자에게 다른 토론자의 생각을 귀띔하기, 브리프 수정하기.

## 4단계: 결과 전달

`.agora/DEBATE.md`를 읽고 사용자에게 다음만 보여준다.

1. 최종 입장 표 (긍정/부정/유보, 입장 변화)
2. 사회자 정리 중 "한 문단 요약"과 "쟁점 지도"
3. 전체 기록은 `.agora/DEBATE.md`에 있다는 한 줄

토론에 대한 너 자신의 의견은 사용자가 묻기 전에는 덧붙이지 않는다.
이어서 할 만한 것 하나를 제안할 수 있다: 같은 질문을 다른 패널로 다시 열기, 또는 사회자가 남긴 질문 하나로 2차 토론.

## 철학자 추가

`philosophers.json`에 항목을 추가하면 된다. 필드: `id`, `name_ko`, `name_en`, `era`, `tradition`, `lens`, `commitments`(3개 안팎), `style`.
`tradition`은 무작위 패널을 다양하게 뽑는 데 쓰인다.
